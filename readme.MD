# 🤖 MultiChatBot

Асинхронный кроссплатформенный бот для организации мультичата и пересылки сообщений между пользователями **ВКонтакте** (библиотека `VKBottle 4.10.0`) и **Telegram** (библиотека `Aiogram 3.x`) и **MAX** (библиотек `maxapi 1.2.2`).

---

## 🛠 Настройка переменных окружения (.env)

Для запуска и корректной работы бота необходимо создать файл `.env` в корневой директории проекта и заполнить его следующими конфигурационными данными:

```env
# Токен доступа к сообществу ВКонтакте (с правами на сообщения)
token=your_vk_group_token_here

# Цифровой ID группы ВКонтакте (без знака минус)
group_id=123456789

# Публичное имя вашего Telegram-бота (без символа @)
bot_name=MyMultiChat_Bot

# Токен вашего Telegram-бота, полученный от @BotFather
tg_token=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
# Токен вашего Max-бота
max_token=f9LHodD0cOJ6i9wqY8CxlCxGSNJwfDdRA7T2wZAg6z5-SB8lUuwWrXLuoKuUpJb1JA8OXBy0L-saVjWmcSqa

# Адрес прокси-сервера (если требуется обход блокировок, например: http://user:pass@ip:port). 
# Если прокси не используется, оставьте поле пустым.
prox=
```

### Подробное описание переменных:

*   **`token`**: Секретный токен сообщества ВК. Получается в *Управлении сообществом -> Работа с API -> Ключи доступа*. У ключа должны быть разрешены права на доступ к сообщениям сообщества.
*   **`group_id`**: Уникальный числовой идентификатор вашего сообщества ВКонтакте.
*   **`bot_name`**: Юзернейм вашего бота в Telegram, необходим для корректной генерации внутренних системных ссылок и логов.
*   **`tg_token`**: Главный токен управления Telegram-ботом.
*   **`prox`**: Строка подключения к HTTP/HTTPS или SOCKS5 прокси. Оставьте строку пустой (`prox=`), если ваш сервер находится в регионе, где API Telegram и ВКонтакте доступны напрямую.

## 🚀 Быстрый запуск

1. Установите зависимости вашего виртуального окружения (`venv`).
2. Создайте и заполните файл `.env` на основе примера выше.
3. Убедитесь, что база данных SQLite инициализирована.
4. Запустите проект:
   ```bash
   python main.py
   ```
